# Credit Card Payments Reminder Hub 💳
A mobile-first web application built with Vue 3 and Tailwind CSS to track credit card payment schedules, monitor balances, and prevent missed due dates.

## ✨ Key Features
- **Smart Categorization**: Automatically groups accounts into *Action Required* (Past Due), *Attention Needed* (Due Soon), *Scheduled* (Upcoming), and *Good Standing* (Settled).
- **Dynamic Summary Footer**: Real-time calculation of total pending debt across all active accounts.
- **Automated Billing Cycles**: Automatically advances payment limit dates by exactly one month when an account status is marked as paid.
- **Account Protection**: Locks payment status toggles and restricts edits for accounts in Good Standing to prevent accidental changes.
- **Mobile-First Design**: Styled layout constrained for clean mobile viewing with sticky navigation and action bars.

## 🛠️ Tech Stack
- **Frontend Framework**: Vue 3 (Composition API)
- **Styling**: Tailwind CSS
- **Icons**: FontAwesome 6
